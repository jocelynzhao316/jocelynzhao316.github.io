# Editing Jocelyn's portfolio

Most updates only require editing **content.js**.

1. Open `content.js` in this repository.
2. Select the pencil icon (**Edit this file**).
3. Change text inside quotation marks, or add a project by copying an existing project block.
4. Select **Commit changes** and confirm.
5. GitHub Pages will republish the website automatically. Updates may take a few minutes.

The other files control the page structure (`index.html`) and visual design (`styles.css`).
